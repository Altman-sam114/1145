# v5.55：战场优先 HUD 与安全区重排

## 版本、背景与目标

- 本轮为 Agent A 给 Agent B 的实现提示词。最新已验收版本是 v5.54，故递增为 v5.55；它是实质 HUD 重构，不是总目标完成。
- 人工要求持续朝 Desert Stormfront 风格 RTS 原型迭代，彻底改善丑陋、占屏、难操作的界面；只做颜色微调不合格。本轮优先重新分配战场与操作空间。后续地图材质/海岸、单位模型及陆海空打击视觉仍需独立实质重做，不能在本轮宣称完成或完全复刻。
- 公开参考检索入口：<https://baike.baidu.com/item/沙漠风暴Desert%20Stormfront/4042982>。只参考可见的战场优先、紧凑资源、小型命令与右上小地图层级；百科混杂的射击游戏描述不作为事实，不复制专有素材。
- 固定方案：左侧五页竖轨、底部仅当前页动作、顶部紧凑资源条、独立有界任务/消息、右侧分带小地图、统一选择/队列容器。B 不再另选方案或扩大范围。

## 非目标与保留边界

- 不改地图/模型、经济、AI、移动、陆海空战斗、生产成本/条件、胜负、迷雾与潜艇侦测规则，不引入依赖/素材或平行玩法系统。
- 保留全部 26 动作、五页、费用与来源提示、队列、选中实体事实、目标血条、待下令高亮及互斥 pending 状态；不得通过删功能腾空间。
- 保持世界/相机语义、HUD z=10000 和世界迷雾；改小地图屏幕框时同步使用同一内容框换算，不能改变世界规则。

## 当前架构依据与关键文件

- `GameScene.swift` 是状态事实核心：`layoutHUD`、`HudPage`、动作字典、选择/队列、小地图、`touchesBegan`、`handleHudPage` 与消息更新共同决定 UI 与命中。
- `GameView.swift` 当前全屏 SpriteView 未可靠传递真实窗口安全区，必须补齐；只允许小型被动窗口观察，不创建新的窗口/控制器框架。
- 主要改 `DesertFrontline/GameScene.swift`，必要时改 `DesertFrontline/GameView.swift`；云端契约仅小范围改 `ci/simulator_probe.py`、共享证据校验/打包脚本及对应云端回归。
- 开始前按 AGENTS.md 读取必读文档，并继承 `v5.54（云端截图朝向与HUD迷雾隔离修复）` 提示词中的 main、账号、用户脏文件、云端证据纪律；如实际文件名不同，以目录中 v5.54 文件为准。

## 实现步骤与视觉/交互标准

1. 把生产 HUD 的框计算、容器关系与命中路由整理为可由运行场景直接复用的单一来源，保持改动局部。不可另写 Python 几何模型，也不可为探针维护一套看似相同的 Swift 影子布局。
2. 采用克制石墨灰/沙金军事控制台，减少荧光、彩色粗边、大装饰卡。移除巨型金币、冗余 THEATER 卡与重复 LIVE 标签。以内置字体粗细/字号形成清楚层级，不靠外部字体或素材。
3. 顶部资源/状态条约 32–40pt，任务与消息各有不相交、可约束的槽。长任务/消息/名称正确换行或截断，不越容器、盖按钮或侵占世界任意区域。
4. 左侧固定五页竖轨；底部只排列当前页动作，不把五页与最多九个动作塞成十四格一行。当前页、可用/禁用、待下令与费用/来源层级清晰。实际像素由 B 在安全区约束下确定，优先保留大面积战场与可读性。
5. 选择/目标/生产队列使用一致且有界容器；选择事实、目标血量、队列进度保留，容器互不重叠。空态紧凑，不用巨大空卡占战场。
6. 小地图分为独立 header/legend、地图内容、footer/zoom 三带。缩放命中至少 44×44pt；内容绘制、世界点投影、逆换算与点击只使用同一个内容框，标题/图例/缩放不得压地图或彼此覆盖。
7. 从实际 `UIWindow.safeAreaInsets` 向场景传递安全区，处理窗口/旋转/尺寸变化；不得把 `.ignoresSafeArea` 的 GeometryReader 值误当真实窗口边缘。所有交互框至少 44×44pt、互不交叠、在有效安全框内。静态条可小于 44pt，但不能冒充可点击控件。
8. 命中顺序统一为页/动作/缩放/地图/静态与轨道或 dock 间隙/世界等明确路由。HUD 静态区域及轨道/dock 空白消费触摸，不向世界穿透、不清除 pending。切页只切 UI，不改变选择、队列或 pending 的互斥状态。保留原多指/相机行为。
9. 每次重建先清除旧节点/框字典，避免隐藏页面留下命中、节点随更新增长。重开 skirmish、场景 resize 与消息更新保持一致。
