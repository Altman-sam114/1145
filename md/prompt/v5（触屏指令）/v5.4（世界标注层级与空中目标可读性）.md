# v5.4 / 世界标注层级与空中目标可读性

## 版本号与版本分配依据

- 版本号：`v5.4`。
- 分配依据：v5.3 云端验收时 Agent C 目视发现世界空间 FOCUS 集火标注被空军实体遮挡；本轮沿用 v5 触屏指令阶段，修复世界标注渲染层级并提升空中目标标注可读性，不新增玩法规则。

## 背景

`focusFireMarkerNode` 挂在 `effectsLayer`（zPosition 190）下且自身 zPosition 为 20，全局有效层级约 210；而空军实体位于 `entityLayer`（zPosition 100）且 `entityZPosition(...)` 对空中单位叠加 170 offset 加位置项（`-y * 0.1`，全图最大约 +128），全局可达约 398。因此 FOCUS 标注文字与目标血条在空中目标（如 Red Fighter）上会被机身部分遮挡，v5.3 冻结截图中 `FOCUS 2 JET 64%` 文字中段不可读。攻击 / 移动 / 停止等 command marker 自身 zPosition 为 264-270（全局 454+），不受此问题影响。

## 目标

1. `focusFireMarkerNode` 的 zPosition 从 20 提升到 240（全局约 430），确保 FOCUS 环、十字线、标注文字和八段目标血条渲染在所有陆 / 海 / 空实体（全局最高约 398）之上、既有 command marker（全局 454+）之下；初始化与每次 `refreshFocusFireMarker` 两处都必须一致。
2. 空中目标的 FOCUS 标注文字额外抬高：目标 `kind.domain == .air` 时文字 y 偏移在既有 `footprint * 0.72 + 12` 基础上再加 14，避免文字与机身轮廓重叠；陆 / 海目标保持原有偏移。
3. 不改变 FOCUS 候选逻辑、`primaryCombatTarget` 统计、标注文案、血条分段配色、marker 内容或任何攻击 / 选择 / 迷雾行为。

## 非目标

- 不改变 `entityZPosition(...)`、entityLayer / effectsLayer / fogLayer / hudNode 层级常量或 command marker zPosition。
- 不新增 HUD 元素、按钮、探针场景或截图；继续复用既有二十三次 simulator launch。
- 不改变单位数值、AI、经济、生产、任务、胜负、潜艇侦测或触屏命中逻辑。
- 不新增外部依赖或素材，不修改签名 Team ID，不纳入 Unity 迁移报告，不做无关重构。

## 当前架构依据

- `GameScene` 层级：`mapNode` 0、`entityLayer` 100、`effectsLayer` 190、`fogLayer` 300、`hudNode` 1000；`focusFireMarkerNode` 是 `effectsLayer` 子节点。
- `entityZPosition(_:)`：陆军 offset 100、空军 170、建筑 90，再叠加 `-position.y * 0.1`。
- `refreshFocusFireMarker(for:)` 在每次选择刷新时重建 FOCUS 标注内容并重设 zPosition。
- FOCUS 目标必须 `isKnownToFaction(..., observer: .player)`，因此其所在 tile 必然可见，标注渲染在 fogLayer（300）之上不会泄露迷雾信息。
