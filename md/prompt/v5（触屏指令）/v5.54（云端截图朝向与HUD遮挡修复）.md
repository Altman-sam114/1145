## 5. 实现步骤

### 5.1 截图方向与证据

1. 在现有 capture 路径收口一个很小的规范化入口，避免实际执行分支与回归各写一套无关联逻辑。当前证据支持：portrait 源图使用有界 `sips --rotate 270`，原生 landscape 源图不旋转。正方形或其他不合约束输入应明确失败，不凭猜测加工成通过。
2. 旋转前把完整 `png_info` 结果记录为每项的 `rawImage`，至少含 bytes、width、height、sha256；记录 `rotationDegrees` 为 270 或 0，以及清晰的 normalization policy/reason；旋转后保持 `image` 为最终正式 PNG 的同一套元数据。
3. 保留原 PNG basename、24 formal launch/PID 记录和最终正式输出。不得裁剪、滤像素、抹系统通知、覆盖战场区域、复制旧图或用 review 副本补数；本轮只做整体角度规范化。
4. 原始尺寸/hash 是旋转前现场记录，不得由最终图倒推或补写。无需默认增加 24 份完整重复 PNG；如原地规范化，只能准确称为原始元数据留证，不宣称 C 能从不存在的 raw 文件重算原始 hash。云端小型角点 fixture 可单独保留为必要结果文件。
5. 把新证据纳入 runner 与 metadata 共同使用的完整性校验：portrait 必须对应 270、最终宽高互换；native landscape 必须对应 0、原始与最终元数据一致；缺字段、角度矛盾、最终 SHA 不符或不再横屏都必须失败。此结构门槛仍不能证明真实 HUD 正向，C 目视不可取消。
6. 规范化命令继续使用既有进程组所有权、最多 30 秒单项上限和共享剩余 deadline，不能另起无界 shell 或绕开总预算。保留失败 summary 与 rawImage 已完成部分，失败不得转绿。

### 5.2 真实 sips 云端角点回归

1. 复用现有 cloud-only 标准库测试入口，或仅新增一个专用小脚本由同一 static step 调用；不增加第三方库和额外 Simulator。
2. 用标准库生成很小的非正方形 RGB PNG，四角/区域使用互不相同且不对称的颜色或像素图案。以明确的坐标期望验证 270 度后每个角点所在的位置，不能只验证尺寸、命令参数或 mock `sips` 成功。
3. 至少一个 portrait fixture 必须通过与实际 capture 相同的规范化入口调用真实 `/usr/bin/sips`，再用测试专用的小范围标准库 PNG 解码/反过滤逻辑检查像素位置；可在测试文件内实现，不扩展生产 `png_info` 为通用图像库。期望坐标要独立写明，不由被测角度函数自行计算出相同错误答案。
4. native landscape fixture 必须证明不执行旋转、像素/原文件 SHA 不变；再覆盖缺少 raw/角度证据、错误角度、尺寸不匹配等新负路径。保留原 watchdog/scheduler 全部用例，不伪造通过数。
5. cloud-only 日志与 `ci-regression-results.json` 记录准确用例数、结果、SHA/run/attempt，并区分真实 sips 角点回归与 fake scheduler 用例。任何失败必须进入现有 static/final CI 门槛。
6. 无论回归是否通过，不能把它宣称为自动识别真实 App 朝向；其证明范围是当前明确策略的角度数学与真实 sips 行为。C 仍审阅全部 24 官方 PNG。

### 5.3 HUD 累计 z 层级

1. 优先用最小改动将 `hudNode.zPosition` 从 1000 提升到有充分余量的明确 UI 层，如 10000；加一条简洁注释说明 fog 自身还包含 +1000 的 child offset，防止之后误降回仅比 fog parent 高的值。
2. 静态审阅当前 world/map/entity/effects/fog 子树的累计 z 上界，说明 10000 的依据；不能只比较 HUD 与 fogLayer 的父节点值。若采用计算上界，必须简单、可重置，不引入逐帧扫描或新渲染系统。
3. 不改 `fogLayer`/fog child 的既有 z、alpha、isHidden 或 `visibleTiles`、`exploredTiles`、`supportRevealTiles`，不移动未知实体到 HUD，不改变潜艇、声呐、FOCUS/ATK 或来袭认知边界。
4. HUD 的内部层级、camera 缩放行为、按钮和 hit frame、inert gap、pending、所有 26 动作及数据更新流保持不变。只提高整棵 HUD 的渲染位置，不随手重构 GameScene 大文件。
5. 云端 24 图重点核对 TACT/BUILD 左端、THEATER/小地图右上、选择卡、资源条和其余 fog 边缘；原有黑色三角不得继续盖住 HUD，战场未知区仍按原 fog 规则隐藏。
