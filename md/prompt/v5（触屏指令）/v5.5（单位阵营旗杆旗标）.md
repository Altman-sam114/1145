# v5.5 / 单位阵营旗杆旗标

## 版本号与版本分配依据

- 版本号：`v5.5`。
- 分配依据：v5.4 已完成世界标注层级修复；本轮参考真实《Desert Stormfront》截图中"每个单位配竖直旗杆 + 国旗"的识别语言，把当前 15x10 纯色矩形 `teamFlag` 升级为旗杆 + 飘旗造型，提升阵营识别度与画面细致度，不改任何玩法数值。

## 背景

真实 Desert Stormfront 截图（itch.io 五张 1280x800 官方图）中每个单位旁有竖直血条塔与国旗小旗，阵营识别一目了然。当前项目 `GameEntity.teamFlag` 是一个 `SKShapeNode(rectOf: 15x10)` 纯色块，位于 `footprint * 0.35 / footprint * 0.45 + 5`、zPosition 22；`setFaction` 换阵营时只重设 `fillColor`。旗帜缺少旗杆和形态，缩远镜头下与血条 / 选择框混在一起。

## 目标

1. `teamFlag` 的形状从矩形改为向右飘的小旗（梯形 / 燕尾任选其一，宽约 13-15、高约 8-10，路径原点在旗杆侧），保持 `fillColor = faction.color`，白色描边细化为 0.8-1.0。
2. 在 `configureEntityNode` 里为 `teamFlag` 添加两个子节点：竖直旗杆（宽约 1.6、高约 14-16 的圆角矩形，浅灰白色，位于旗布左缘下方延伸）和杆顶小圆头（半径约 1.2，同色）；子节点不参与 `setFaction` 换色，换阵营时仅旗布变色即可。
3. `teamFlag` 挂点微调为旗杆底部对齐原位置（视觉重心不明显移动），整体 zPosition 保持 22，不遮挡血条（20/21）之上的 label（23）。
4. 所有单位与建筑通用；捕获 / 换阵营（`setFaction`）后旗布颜色正确切换；不改变迷雾隐藏逻辑（旗标随实体父节点整体隐藏）。

## 非目标

- 不引入外部素材或纹理，继续用 SKShapeNode 矢量构造。
- 不改变血条、label、选择圈、veterancy、capture 等兄弟节点的布局与 zPosition。
- 不改变任何玩法数值、AI、经济、迷雾、胜负；不新增探针或截图；继续复用二十三次 simulator launch。
- 不修改签名 Team ID，不纳入 Unity 迁移报告，不做无关重构。
