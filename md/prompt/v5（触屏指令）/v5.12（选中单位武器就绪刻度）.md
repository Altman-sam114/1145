## 背景与参考

- 参考对象固定为百度百科 lemma id 4042982 对应的 Noble Master Games《沙漠风暴 Desert Stormfront》，不是其他同名作品：
  https://baike.baidu.com/item/%E6%B2%99%E6%BC%A0%E9%A3%8E%E6%9A%B4Desert%20Stormfront/4042982
- 官方 press sheet / trailer 中的触屏 RTS 画面把选择圈、单位模型和战斗状态放在同一战场层，玩家应能在不离开地图的情况下快速判断单位是否准备好下一次射击。本轮只借鉴“选择圈边缘的低占用状态提示”这一信息层级，不复制素材、纹理、音频、布局或其他项目 UI。
- v5.11 已把右侧选择面板的 Weapon ready / Reload 文字按 attackTimer 分层着色，但多选时玩家仍只能读到汇总 Ready/Reload，无法迅速看出具体哪一辆车、哪架飞机或哪艘舰已经可以开火。选择圈边缘的短刻度可以补充这一信息，同时避免增加面板行数和触屏操作负担。

## 本轮目标

1. 为 GameEntity 预创建一个实体内的武器就绪视觉根节点和 3–4 个固定几何的微型刻度 / 短弧，放在现有绿色选择椭圆的低侧外缘。节点在实体配置时一次性创建，禁止在 update、updateHUD、refreshSelection 或每次刷新中 addChild。
2. 仅对满足以下全部条件的玩家作战机动实体显示刻度：faction == .player、存活、isOperational、非结构、kind.damage > 0，并且当前在 selectedIDs 中。敌方、未知敌方、建筑、施工中的结构、无伤害的 Mechanic、死亡 / 移除实体必须隐藏刻度；没有选中单位时不得留下世界节点。
3. 刻度状态只读既有 attackTimer，并按当前实体的 effectiveAttackCooldown(for:) 归一化进度，不引入第二份冷却状态：
   - attackTimer <= 0.05 沿用 Weapon ready 的既有门槛，3–4 个刻度全部使用清晰的青绿 / 青色就绪色；
   - 冷却中以 1 - clamp(attackTimer / max(effectiveAttackCooldown(for: entity), 0.2), 0...1) 得到就绪进度，按固定刻度逐段显示琥珀色已恢复部分，未恢复部分用低对比深色保留槽位；不得把 attackTimer 写回任何新字段，也不得用 kind.attackCooldown 绕过老兵冷却倍率；
   - 超出范围、负值或异常 duration 必须 clamp 到合法视觉范围，不能造成 NaN、反向缩放或越界节点。
4. 视觉统一服务陆、海、空机动单位（Humvee / AA Truck / Tank / Artillery、Helicopter / Fighter、Battleship / Submarine / Carrier），刻度保持相对选择椭圆的固定尺寸，不因 footprint、镜像或镜头缩放改变布局逻辑。上侧旗标、竖直六格耐久塔、实体短码、FOCUS / ATK 文字和生命条的空间优先级高于刻度，因此刻度固定在低侧或外缘，不能挡住这些既有信息。
5. 刻度随实体节点树移动、镜像、战争迷雾、隐身 / 声呐可见性、维修、战损、死亡和重开 skirmish 一起生效；不得放入 effectsLayer，不得产生独立 world-level 节点或敌方位置泄露。
6. 不新增文字、按钮、HUD 行、页签、面板尺寸或触摸命令。v5.11 的选择面板颜色、目标生命条、FOCUS / ATK、来袭威胁、旗标、耐久塔、海空命中和现有模型必须保持原行为。

## 当前架构依据

- DesertFrontline/GameScene.swift 是唯一事实核心。GameEntity 当前持有 selectionNode（椭圆选择圈）、attackTimer、kind、faction、hp、isOperational 以及实体自有的旗标、六格 healthTowerNode、模型、航迹、投影、战损和命令节点。
- configureEntityNode(_:) 一次性构造实体树和选择圈：选择圈当前是 SKShapeNode(ellipseOf:)，初始隐藏、相对实体 zPosition = -1，并挂在 entity.node 下。新根节点 / 刻度应继续挂在 entity.node 或 selectionNode 子树内，使用固定相对坐标和低占用 z 序；不能脱离实体树。
- refreshSelection() 每次选择变化时按 selectedIDs 切换 selectionNode.isHidden，并刷新命令意图、FOCUS、射程 / 覆盖 / 威胁视觉。由于 attackTimer 每帧变化，刻度刷新不能只放在选择变化分支；应在 updateHUD() 的每帧只读刷新路径，或与其等价且每帧执行的既有视觉入口中更新预创建节点。更新只允许改变 isHidden、strokeColor、alpha、必要的 lineWidth / glowWidth 等属性，不得逐帧建 path / node。
- updateHUD() 在刷新 refreshIncomingThreatVisuals、refreshCommandIntentVisuals、refreshFocusFireMarker 和 updateSelectionInfoPanel 后每帧运行；可新增一个小型 refreshWeaponReadinessVisuals(for:)，但必须复用当前选中实体集合，不创建第二套选择状态。
- updateCombat(dt:) 每帧用 entity.attackTimer = max(0, entity.attackTimer - dt) 递减；开火前要求 attackTimer <= 0，开火后写入 effectiveAttackCooldown(for:)。effectiveAttackCooldown(for:) 已包含当前 VeterancyRank.cooldownMultiplier 并以 max(0.2, ...) 限幅；刻度进度必须以该 helper 为分母，保持老兵单位的视觉与实际冷却一致。
- updateSelectionInfoPanel(selected:) / selectionInfoRowColors(for:) 已将 Weapon ready / Reload 颜色和来袭威胁接入既有面板；v5.12 只补选择圈边缘视觉，不把刻度状态反向写入面板或战斗对象。
- 实体镜像通过 entity.node.xScale（空军和敌军 capture 会设为 -1），实体父树也承载迷雾 / 隐身和销毁。刻度几何应继承该镜像，不要手动改世界坐标或复制一套 fog 检查。
- focusFireMarkerNode、攻击目标 marker、来袭方向、旗标和耐久塔分别位于已有世界 / 实体层级；刻度只能在实体树内低面积显示，不能改变这些 marker 的 zPosition、统计、标签和生命周期。
