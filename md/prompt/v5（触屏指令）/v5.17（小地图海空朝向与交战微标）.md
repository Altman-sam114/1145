# v5.17 / 小地图海空朝向与交战微标

## 版本号与版本分配依据

- 版本号：`v5.17`。
- 分配依据：v5.16 日志提交 `72ba2a088240b092b6e132b81ba4a4151ecad4a1` 已通过实现与日志 artifact 双重验收；下一轮继续做一个不扩张玩法状态的海空触屏读图增量。
- 公开参考使用 [Desert Stormfront 官方 press sheet](https://www.noblemaster.com/press/sheet.php?p=desert_stormfront)、[开发者 itch.io 页面](https://noblemaster.itch.io/desert-stormfront)、[官方海岸截图](https://img.itch.zone/aW1hZ2UvNzU1NDk3LzQyMjQ4MjgucG5n/original/96Bdey.png)、[IndieDB 海战截图](https://media.indiedb.com/images/games/1/19/18873/screen_dsf_v02_05.png) 和 [Pocket Gamer 评测](https://www.pocketgamer.com/desert-stormfront-rts/)。公开资料只支持触屏 RTS、海陆空单位、海岸同屏、小地图和编队调度的方向；本项目的朝向齿与交战微标是原创的展示推断，不宣称为原作 UI。

## 背景

- 当前 `updateMinimap()` 为存活且玩家已知实体创建结构方块、陆军圆点、空军三角和海军菱形；选中实体已有青色圈，已有来袭快照时已有红橙告警圈。
- 海军/空军单位在主战场有航迹、投影、命令意图线、目标环和导弹/炮迹，但 210×158 小地图只有静态领域符号；玩家需要额外移动镜头才能判断海空编队朝向和选中单位的交战方向。
- `GameEntity` 已有 `attackTarget`、`attackMoveDestination`、`destination`、`path` 和 `node.xScale`；`incomingThreatsByTargetID` 已在 `refreshIncomingThreatVisuals(...)` 中按玩家已知边界建立。本轮只把这些既有事实转换为小地图上的少量短齿形节点。

## 本轮目标

1. 仅为海军和空军 minimap blip 增加 4–6pt 的只读朝向齿：优先使用合法且玩家已知的 `attackTarget`，其次使用 `attackMoveDestination`、`destination`、`path.last`，最后使用既有 `node.xScale` 的左右朝向回退。
2. 仅对选中的 Blue 海军/空军，在存在合法且玩家已知 `attackTarget` 时增加短红色目标方向齿；若 `incomingThreatsByTargetID` 有已知来袭攻击者，再增加短琥珀来袭方向齿。
3. 朝向齿使用程序化 SpriteKit `SKShapeNode` 线段/箭头，不新增文字、纹理、按钮、命中区、状态字段或外部依赖；每次 `updateMinimap()` 重建 blip 时随节点清理。
4. 保持当前领域符号、选中圈、来袭告警圈、小地图相机框和 minimap 点击跳转不变；微标不能覆盖小地图边界或泄露未知敌方目标 / 未侦测潜艇。

## 非目标

- 不修改 `updateMovement(...)`、`updateCombat(...)`、`fire(...)`、AI、生产、路径、伤害、冷却、攻击合法性、触控命令、战争迷雾、`visibleTiles`、`exploredTiles`、`supportRevealTiles` 或 `revealedUntil`。
- 不新增真实航向字段、目标状态、巡逻、编队状态、旋转炮塔、航向控制或完整 360° 航行模拟；无移动意图时只允许使用左右镜像回退。
- 不把固定 capture 解释为真实移动过程、触控命中、动态 AI、连续战斗、潜艇隐身转换或性能验证。
- 不新增第 25 次 workflow launch，不修改 `.github/workflows/ci-results.yml`，不修改或暂存人工 Team ID / `md/unity分析/`。

## 当前架构依据

- `updateMinimap()` 先过滤 `isKnownToFaction(entity, observer: .player)`，再把 blip 放在 `minimapPoint(forWorldPoint:)`；未知敌人不能创建任何方向 cue。
- `minimapBlipNode(for:)` 是领域符号、选中圈和告警圈的共享构造入口，本轮将方向齿集中放在这里，避免在海军/空军战斗 helper 中复制 HUD 逻辑。
- `refreshIncomingThreatVisuals(...)` 在 `updateHUD()` 之前刷新 `incomingThreatsByTargetID`，因此可以只读复用 `incomingThreatsByTargetID[entity.id]`；不得重新扫描全图、写入实体状态或绕过 fog。
- 目标方向必须通过 `knownMinimapAttackTarget(...)` 再检查 `target.isAlive`、`entity.kind.canAttack(target.kind)` 和玩家已知条件；未侦测敌方 Submarine/HQ/其他敌人不得通过方向齿泄露。
- 方向齿挂在 blip 本地 node，使用 minimap 的世界坐标方向，不重复套用实体 `xScale`；只有默认左右回退读取 `node.xScale`。
