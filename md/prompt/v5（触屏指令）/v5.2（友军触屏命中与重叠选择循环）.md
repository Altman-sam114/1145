# v5.2 / 友军触屏命中与重叠选择循环

## 版本号与依据

- 版本号：`v5.2`。v5.1 已解决敌方小目标集火，本轮对称解决己方小模型与重叠编队难以精准选择的问题。

## 目标

1. 为玩家单击选择增加约 26pt 的屏幕尺度最小命中半径，不随相机缩放退化为过小世界范围。
2. 同一点击邻域存在多个己方单位时，按距离与 entity id 稳定排序；重复单击循环选择下一单位。
3. 循环成功显示 `SEL i/n CODE` 世界反馈，选择面板与选择圈立即对应新单位。
4. 精确敌军点击继续优先执行攻击；双击己方机动单位继续选择视野内同型单位；空地移动、框选、迷雾、潜艇、AI 和战斗数值不变。
5. 新增 capture-only `selection-cycle` 与 `simulator-selection-cycle.png`，云端 probe 扩展为二十二次。

## 非目标

- 不新增 HUD 动作，不改变 TACT 九动作与全局 26 动作。
- 不改变敌军命中半径、攻击目标合法性、移动、伤害、AI、迷雾或潜艇侦测。
- 不引入外部依赖或素材，不触碰 Team ID 与 Unity 报告。

## 实现

- 在 `GameScene` 保存最近点击位置、候选 ID 顺序和最近循环实体 ID；状态不持久化、不供 AI 使用。
- `playerSelectionCandidates(at:)` 只收集存活玩家实体，半径为 `max(footprint * 0.95, 26 * cameraRig.xScale)`，按距离排序，0.5 内按 id 打平。
- `selectPlayerEntity(...)` 在点击邻域与候选集合保持一致、当前仍是上次单选时前进一位，否则从最近候选开始；选择变化后刷新 selection / HUD。
- `handleWorldTap(...)` 先保留精确敌军命中；精确己方双击走旧同型选择，单击或未精确命中但落在辅助范围内时走新 helper。
- 框选、ARMY、控制组召回与 SKRM 清 cursor；其他选择变化通过 selection-scoped 条件自然失效。
- capture 编排紧邻的 Blue Humvee / Tank / Artillery，真实调用 helper 两次并持久显示第二候选 `SEL 2/3 TNK`。
