### 3. 生产拟合：原文不变、原生截尾、实际 bbox 对齐

优先采用无需缓存架构的原生方案：`label.text` 本身始终是完整 canonical 输入，fitter 不写它。项目最低 iOS 17，已只读核对 SDK `SKLabelNode.h` 与 Apple 的 `numberOfLines`、`preferredMaxLayoutWidth`、`lineBreakMode` 公开文档：相关 API 自 iOS 11 可用，单行数量为 1，非零 preferred width 后应用 line-break，tail truncation 为默认模式。头文件部分说明使用 multiline 措辞，API 存在不等于单行实际 bbox/可读性已证明；仍必须以本轮原生测量与 PNG 为准。

每次 fit 对每个注册 label 从确定输入重算：

1. 保留完整 `text`，清除上次 native preferred width 限制以测真实自然 bbox，恢复该注册项原 base font，沿用原 `xScale=1` 的正常行为；不降低现有 floor `min(8, baseFontSize)`、不改 font family/yScale/zRotation/父变换。
2. 从 slot 和既有 horizontalAlignmentMode 得到固定初始锚点（left=minX、center=midX、right=maxX；y=midY），每次由此重算，不在上次修正位置上累计偏移。用当前真实自然 `frame` 在原 floor/base 范围内拟合字号，再设置 `numberOfLines=1`、`lineBreakMode=.byTruncatingTail` 和 slot 宽的 `preferredMaxLayoutWidth`；不得逐字符删串或用推测字符宽度。
3. 读取原生布局后的真实父局部 bbox。不论是否需要缩字，都按 left/center/right 将 bbox 的 minX/midX/maxX 对齐 slot 对应边/中心，按 `slot.midY - bbox.midY` 垂直居中；实际位移只用于 label.position，不改 slot。必要时有限再测/纠正，最终仍由实际 frame 断言合框。
4. fitter 自身每 label 的测量/调整步数须有明确小上界：最多 8 次 frame 读取、除 base reset 外最多 2 次字号调整和 2 次位置纠正，允许更少；无按字符/文本长度循环、无额外测量节点、无每帧分配审计字典/快照。CI 快照仅在既有一次性契约内创建。
5. 不建立 source/output 猜测缓存、永久缩字状态、中央 setter 改造或第二套 HUD 文本状态；后续完整短文本自然从 base 重算，不能因前次长文本停留在最小字号。`label.text` 是源文本，不能把它误称为已呈现的截尾字串。

若 native 单行截尾实际不满足 bbox/source/幂等门槛，准确留证失败交 X，不在同轮偷偷换缓存方案、改字体、改几何或放宽断言。无 App 证据时也不能凭静态算法宣称根因已修复。

### 4. HUD25 实测：保持九类，增强原 labels

保留原 5 尺寸×5 页、九类 checks 的 key 和原断言；下述新增标签断言全部 AND 到既有 `checks.labels`，不是第十类 gate。原选择信息行检查保留。对注册标签实测而非构造替代 label：

- 在每组合依次审计 normal、long1、short、long2、restored、rebuilt 六阶段；每阶段都调用实际生产 fitter 两次，按稳定 ID 比较完整 source、实际 bbox/position/fontSize/xScale/yScale/zRotation 与父对象/局部坐标身份。重复调用应完全一致，不新增漂移容差或拿 0.5 的包含容差掩盖累计漂移。
- normal 保存完整原文（区分 nil/空串），long1/long2 使用同一固定有界长串；至少保留原六个 mission/detail/message/selected/queue/selection-title 压力对象，并在不改可见性的情况下覆盖其他注册标签。short 使用固定短串；凡 base font 的实际自然 bbox 可容纳的短串，必须恢复 base 字号，报告 eligible/recovered 数量，不能永远沿用上次缩小值。eligible 只能由 base font、无限制 preferred width 时的真实 frame 得到，不从已缩小结果反推；每 case 至少一个 eligible 且 recovered=eligible，不虚填零回避恢复检查。long2 必须与 long1 的源文本和拟合快照一致。
- 原包含判断 `slot.insetBy(dx:-0.5,dy:-0.5).contains(label.frame)` 保持；对非空可见的正常/压力文本，实际 bbox 必须 finite 且 width/height 都大于 0，source.text 在 fit 前后完整不变。不得以零 bbox、隐藏 label/祖先、alpha 清零、空串、透明色或退出枚举获得 contains 绿；原可见性/颜色/alpha 必须保留。空标签仍比较 source/父坐标/位置/scale，不把空 bbox 冒充可见文字成功。
- restored 恢复临时保存的原文后，对比 normal 的拟合结果；rebuilt 沿用原 `layoutHUD/updateHUD` 重建，再按 ID 对比相同源文本、slot/逻辑 parent、font/position/scale/bbox。保留原 node-count/stale-targets 检查，不用重建丢掉压力证据。
- 契约开始时保存实际窗口/页原文与拟合快照；结束时恢复既有尺寸/inset、选择/队列/pending、镜头、消息/颜色/alpha、触摸状态，并实测恢复后 fit 两次。实际窗口标签原文、逻辑父坐标和拟合状态不得漂移；该标签恢复结果归入 labels 审计并 AND 到原 `stateRestored`，保留原 fingerprint，不替换原恢复检查。正式 24 次 launch 不带合成压力状态。

### 5. 有界、可核验报告，不改变 trace 限制

- 在原 schema1 报告的每个 matrix row 增加 `labelAudit`（自身 `schemaVersion=1`、`coordinateSpace=label-parent-local`）；含完整稳定 labelIDs、六阶段测量/非空/合框/正 bbox/source unchanged/重复 fit/父变换一致计数或明确结果、短串 base 恢复 eligible/recovered、long 往返及原文恢复/重建比较结果。另记录 actual-window 标签恢复摘要，与原 `stateRestored` 一致。不得只有一个无证据的总 true。
