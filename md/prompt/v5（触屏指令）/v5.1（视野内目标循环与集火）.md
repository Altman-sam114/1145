# v5.1 / 视野内目标循环与集火

## 版本号与分配依据

- 版本号：`v5.1`。
- `v5.0` 已用 STOP 降低错误命令的撤销成本；本轮继续同一触屏指令阶段，解决高密度交战中小模型难以精准点选的问题，因此递增为 `v5.1`。

## 背景

Noble Master 官方 Desert Stormfront press kit 强调面向 casual / touch-screen players 的简化实时操作，官方 iOS 截图也持续使用集中、高对比的上下文命令。当前 Desert Frontline 已能直接点击玩家已知敌军下达攻击、显示 `ATK` / `FOCUS`、目标 HP 和命令意图线，但在单位重叠或海空混战时仍依赖精准触摸敌方小模型。

## 本轮目标

1. 在 TACT 单排命令条新增 `TGT`，位于 STOP 与 AMOV 邻近位置，保留全部旧动作。
2. 选中玩家作战单位后，`TGT` 只循环当前相机视野内、存活、敌方、玩家已知且至少能被一个选中单位攻击的目标。
3. 候选按目标到选中作战编队中心的距离排序，距离近似相同时按实体 ID，保证稳定、可解释。
4. 当前 selection 已有 TGT cursor 且目标仍在候选中时，下一次 TGT 前进到下一候选；到末尾后循环到第一候选。首次使用优先从当前 primary attack target 前进，无当前目标时从第一候选开始。
5. TGT 复用直接点击攻击的命令执行 helper：只给 `canAttack(target.kind)` 的选中玩家机动单位分配目标，并清理它们的 HOLD、Carrier guard anchor、AMOV、destination 和 path。
6. TGT subtitle 显示 `select`、`none` 或当前 / 下一目标短码与候选位置；可用时使用高对比红色样式。
7. 成功切换显示 `Target i/n: ... assigned` 顶部消息、Carrier guard release 组成反馈、目标 `ATK i/n CODE` marker、命令意图线与既有 FOCUS / 目标 HP UI。
8. 新增 capture-only `target-cycle` 和 `simulator-target-cycle.png`，把云端 simulator launch probe 从二十次扩展为二十一次。

## 非目标

- 不自动寻找全图敌军，不选择相机外目标，不泄露战争迷雾或未侦测 Submarine。
- 不新增攻击优先级 AI、弱点系统、范围伤害或武器类型选择。
- 不改变攻击伤害、射程、冷却、寻路、攻击站位、AI、经济、生产、任务、胜负或单位数值。
- 不把建筑或无攻击力单位视为 TGT 攻击者；目标仍可按现有 `canAttack(...)` 成为合法单位 / 建筑。
- 不引入外部依赖或素材，不触碰用户 Team ID 与 Unity 报告。

## 当前架构依据

- `handleWorldTap(...)` 的敌军分支是当前玩家直接攻击入口，已按攻击者逐个清理互斥命令并显示 marker / release feedback。
- `selectedMobilePlayerUnits()`、`EntityKind.canAttack(...)`、`isKnownToFaction(..., observer: .player)` 和 `visibleWorldRect()` 分别提供玩家选择、武器合法性、迷雾 / 潜艇侦测与当前相机范围边界。
- `primaryCombatTarget(for:)` 已按当前选中作战单位统计 primary target，可作为无额外 cursor 的循环起点。
- `refreshSelection()` / `updateHUD()` 会同步命令意图线、FOCUS marker、目标摘要与按钮 subtitle。
- `prepareCICaptureScene()` 按 `DESERT_CI_COMMAND_MARKER` 分流确定性场景，普通 App 不进入 capture-only 写入。

## 实现步骤

1. 新增 `HudAction.cycleTarget`、`TGT` title、TACT 排列、按钮颜色、副标题和可用样式。
2. 新增纯查询 helper：
   - 过滤选中、存活、玩家、operational、非结构、damage > 0 的作战单位。
   - 过滤当前 `visibleWorldRect()` 内的玩家已知敌军。
   - 要求至少一个选中作战单位 `canAttack(target.kind)`。
   - 按距选中编队中心的距离，再按 id 排序。
3. 从 `handleWorldTap(...)` 抽取共享 direct attack helper；保持旧点击攻击消息 / denied marker / 字段清理语义，并在成功后主动刷新 selection 与 HUD。
4. 实现 selection-scoped TGT cursor：只保存最近 TGT 目标 id 与当时 selection id 集合；selection 改变、直接点击攻击、MOVE、HOLD、STOP、AMOV 或 SKRM 时失效 / 清空，不进入持久状态、不供 AI 使用。首次 TGT 从 `primaryCombatTarget(for:)` 找当前候选 index，后续优先使用有效 cursor，计算循环后的目标并调用共享攻击 helper。无作战单位提示选择，无候选提示当前视野没有合法目标。
5. target-cycle capture 编排四个 Blue 作战单位与三个距离递增的已知 Red 地面目标，先让四单位共享第一目标，再调用真实 TGT helper切到第二目标；将其他 Red 实体移出当前视野，避免候选污染。
6. capture 截图必须显示 TGT subtitle 的第二候选位置、`ATK 2/3` marker、`FOCUS 4`、目标 HP、四选战斗摘要、命令意图线、小地图和完整九动作 TACT 单排。
7. workflow 新增第二十一次 target-cycle 启动、清理列表与 manifest 条目；同步 README、flow、flowchart 和 test。

## 验收标准

- TACT 九个动作和五个页签保持完整单排，无文字溢出或遮挡。
- TGT 无选择显示 `select`；无合法目标显示 `none`；有候选显示短码和位置 / 总数。
- 连续 TGT 在同一候选集合中稳定循环；当前目标失效、出视野或不再已知时自然回到第一合法候选。
- TGT cursor 只在 selection 不变且仍指向合法候选时生效；selection 改变、直接攻击、其他移动类命令或 SKRM 后不沿用 stale cursor。
- 只有合法攻击者被改写命令；不能攻击该目标的已选单位保留原命令。
- 相机外敌军、fogged 敌军与未侦测 Submarine 不进入候选、不出现在 subtitle / marker / 消息。
- 直接地图点击攻击保持原行为，并与 TGT 共享字段清理与 Carrier guard release 路径。
- `simulator-target-cycle.png` 清楚显示 `TGT ... 2/3`、`ATK 2/3 ART`、`FOCUS 4 ART 57%`、目标生命条、四选摘要、四条红色攻击意图线、小地图与九动作单排。
- 最新 artifact 的 generic device build、simulator build、二十一次 launch / alive / PNG 均成功，JUnit 0 failures，无 crash / SIGABRT / watchdog / fatal。

## 风险

- TACT 增至九动作，紧凑横屏按钮会进一步变窄；subtitle 必须保持短码格式并由云端截图目视检查。
- 直接攻击抽 helper 触及共享玩家入口，必须逐字段保持原语义并避免把 TGT 的循环文案带入普通点击攻击。
- capture 场景必须移走其他已知 Red 实体，否则候选数量与排序会受初始编队影响。
- `isKnownToFaction` 对玩家依赖 `visibleTiles`，capture 必须在位置编排后更新 fog，再查询候选。

- 禁止给不能攻击当前目标的选中单位清除旧命令。
- 禁止增加全图自动索敌、AI 作弊视野或并行目标状态机。
