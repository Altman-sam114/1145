# v5.6 / 航母甲板与舰岛细化

## 版本号与版本分配依据

- 版本号：`v5.6`。
- 分配依据：v5.5 已完成单位旗标；本轮参考真实《Desert Stormfront》航母造型（蓝灰甲板、白色跑道标线、右舷舰岛），细化当前只有船体 + 素甲板 + 单斜线的 Carrier 模型，提升海战画面细致度，不改任何玩法数值。

## 背景

`addNavalUnitBody` 中 `.carrier` 分支目前仅三层：`shipHullPath(92x32)` 船体、72x18 素灰甲板、一条 55x2 斜白线。对比 Battleship 的分层装甲 / 炮塔 / 舰桥 / 桅杆 / 雷达细节明显偏简陋；真实参考图中航母是"斜角跑道标线 + 舰岛 + 甲板边缘线"的清晰母舰形象。Carrier 是可生产舰载机的高价值单位（2800），值得对应的视觉分量。

## 目标

1. 甲板改为分层：外圈甲板边缘线（深色描边）、主甲板（蓝灰 `UIColor(white: 0.30)` 系）、斜角跑道区（稍亮灰、带 0.18 左右 zRotation）。
2. 跑道标线组：中线虚线（3-4 段白色短杆沿跑道方向排布）、跑道两端各一条横向白色门槛线；替换原单条斜线。
3. 右舷舰岛：小型分层结构（底座 + 塔楼 + 天线杆），位于甲板右前方（x 约 +14，y 约 -8 一带），使用 navalColor 加深色，带 1-2 个阵营色舷窗点（Blue 青色 / Red 橙红，与 Battleship 舷窗语言一致）。
4. 甲板停机标识：2 个小圆形停机位圈（白色细描边、透明填充）位于甲板后段。
5. 所有新增节点均为 `base` 静态子节点，zPosition 在 0-8 内分层；不改 footprint、碰撞、选择圈、血条、旗标、镜像（xScale 翻转）与迷雾行为。

## 非目标

- 不改 Battleship / Submarine 造型，不改航母生产、guard anchor、舰载机、攻击、AI、经济等任何玩法逻辑。
- 不新增探针或截图；继续复用二十三次 simulator launch（carrier-strike 截图已含 Carrier，可作验收图）。
- 不引入外部素材；不修改签名 Team ID；不纳入 Unity 迁移报告；不做无关重构。
