# v5.38：海空选中卡域色彩层级

## 版本分配依据

继 v5.37 单选卡域标签，继续递增同一信息层级的视觉增量。

## 目标

为单选卡 `LAND/AIR/SEA/SUB/BASE` 域标签提供稳定的语义色：陆军沙绿、空军天蓝、水面舰青色、潜艇紫色、结构沙金；若实体处于合法来袭威胁，既有红橙告警优先级保持最高。

## 非目标

不改变单位属性、HP、战斗、迷雾、命令、AI、触摸命中区域、动画或生产状态；不新增依赖、素材、本地测试或探针。

## 实现与验收

在 `updateSelectionInfoPanel` 和 `selectionDomainColor(for:)` 中只读设置标题颜色，更新 README 后 `git diff --check`，提交 `main` 并推送。云端 manifest 必须匹配最新 commit，generic iOS build、lint、simulator launch 和 24 张 PNG 全部通过；海空、潜艇、建筑和来袭截图不得出现标题颜色残留或遮挡。

## CI 要求

不运行本地 Xcode、Simulator、simctl 或本地探针。验收下载 `/private/tmp/desert-frontline-c-review-<run_id>/` 未加密 artifact，核对 manifest、JUnit、logs、PNG 与 xcresult。
