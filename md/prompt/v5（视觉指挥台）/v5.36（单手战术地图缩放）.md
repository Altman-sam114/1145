# v5.36：单手战术地图缩放

## 版本分配依据

继 v5.35 战区信息层级与资源卡优化，继续递增视觉与移动端操作增量。

## 背景与目标

Desert Stormfront 的移动 RTS 需要在地图观察与战斗命令之间快速切换。当前已有双指缩放，但单手操作缺少显式入口。本轮在小地图下方增加 `−` / `+` 缩放按钮，复用现有相机缩放边界与小地图 camera box，提升易用性。

## 非目标

- 不修改移动、攻击、生产、AI、迷雾、任务或胜负规则。
- 不新增相机状态、外部依赖、素材或本地探针。
- 不运行本地 Xcode、Simulator、simctl 或本地玩法探针。

## 实现步骤

1. 在 `GameScene` HUD 状态中缓存两个语义命中框，并在 `layoutHUD()` 的 minimap 下方绘制低对比 `−` / `+` 按钮。
2. 在 `touchesBegan` 中优先处理按钮，调用统一的 `adjustCameraZoom(by:)`，使用既有 `minCameraScale` / `maxCameraScale` 与 `clampCamera`。
3. 刷新 minimap camera box 并显示短暂 `Zoom in/out` 消息；地图世界点击和 HUD command dock 不穿透按钮。
4. 更新 README、flow 和测试口径，执行 `git diff --check` 后提交 `main` 并推送。

## 验收标准

- 云端 manifest 的 commit、branch、runId 与 `origin/main` 一致。
- generic iOS build、static checks、project lint、simulator launch 均 success。
- 24 张 PNG 中 minimap 下方缩放按钮可辨识、未遮挡选择卡或 command dock；其余地图、海战、空战和命令截图无回归。

## CI、artifact 与禁止项

固定使用 `main`，不创建候选分支或 PR 流。Agent C 下载 `/private/tmp/desert-frontline-c-review-<run_id>/` 的未加密 artifact，核对 manifest、JUnit、build log、failure summary、simulator log、24 张 PNG 和 xcresult。不得用本地构建替代云端证据，不得绕过现有触摸优先级或迷雾边界。
