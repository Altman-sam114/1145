# v5.35：战区信息层级与资源卡优化

## 版本分配依据

继 v5.34 战场 HUD 视觉指挥台重构与启动稳定性修复，继续沿单轮视觉增量递增。

## 背景与目标

参考 Desert Stormfront 的核心构图：地图保持最大视觉权重，资源、任务、战区状态、小地图和底部快捷命令各有明确区域。优化 HUD 的视觉层级，消除资源卡底部文字贴边，并在小地图上方增加固定战区身份条，方便玩家快速判断当前战区与战争迷雾状态。

## 非目标

- 不修改 GameScene 的经济、生产、战斗、AI、迷雾、胜负或触摸状态流。
- 不新增外部素材、依赖、持久化状态或新的探针次数。
- 不运行本地 Xcode、Simulator、simctl 或本地玩法探针。

## 当前架构依据

`layoutHUD()` 是 HUD 的唯一视觉构建入口，`HUDPalette` 是颜色来源；`updateHUD()` 只刷新现有状态文字。小地图由 `addMinimap(frame:)` 创建，所有 HUD 节点挂在 `hudNode`，触摸命中仍使用独立 hit frame。

## 实现步骤

1. 将左上资源卡调整为 348×82，并重新安排标题、资源数字、收入行与徽标的垂直间距。
2. 在小地图上方增加不参与交互的 `THEATER / COASTAL SECTOR` 战区状态条，显示 `MAP LINK / FOG ACTIVE / LIVE`。
3. 更新 README 的当前 HUD 行为事实。
4. 运行 `git diff --check`；确认只提交本轮 GameScene、README 和提示词文件。
5. 在 `main` 上提交并推送，等待 GitHub Actions generic iOS build、simulator launch 与 24 张 PNG 探针。

## 验收标准

- 云端 manifest 的 branch、commitSha、runId 与最新 `origin/main` 一致。
- generic iOS build、static checks、project lint、simulator launch 均 success。
- 24 张原始 PNG 中，资源卡文字不贴边，战区状态条位于小地图上方且不遮挡任务卡、地图、小地图或命令栏。
- 既有命令页面、按钮语义 hit frame、pending 高亮、迷雾与海空战斗截图保持可读。

## 风险和禁止项

保持未完工建筑、潜艇隐身、玩家认知过滤与所有实体视觉生命周期不变；不得把固定战区文案误写成新的玩法状态。

## CI、artifact 与 Agent C 验收

固定使用 `main` 与 `origin/main`，不得创建候选分支或 PR 流。Agent B 只做本地轻量检查后 commit/push；云端必须上传未加密结果包。Agent C 下载 `/private/tmp/desert-frontline-c-review-<run_id>/`，核对 `ci-artifact-manifest.json`、`junit.xml`、`xcodebuild.log`、`ci-failure-summary.md`、`simulator-launch.log`、24 张 PNG 与 `DesertFrontline.xcresult`，不以本地构建替代云端证据。
