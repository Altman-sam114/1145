# v5.34：全面重构战场 HUD 视觉

## 版本分配依据

当前 `origin/main` 最新正式记录为 v5.32，工作树已有未跟踪 v5.33 提示词但不属于本轮改动。本轮是其后的独立 UI 视觉增量，分配为 v5.34。

## 背景

Desert Frontline 已具备陆海空 RTS 核心玩法、SpriteKit 地图、小地图、任务、选择面板和五页命令条，但 HUD 仍使用早期的高饱和块状按钮与不统一面板，信息层级、战场可读性和触控优先级不足。官方 Desert Stormfront 的参考画面采用战场占主体、深色战术框、金色任务强调和明显的单排触控栏。本轮把该结构转译为当前项目的现代深色沙漠指挥台风格。

## 目标

- 重做 `GameScene.swift` 中 HUD 的统一视觉语言：深色玻璃面板、沙金任务强调、青色海空信息强调、红色告警强调。
- 改善顶部资源条、任务卡、状态卡、选择信息卡、小地图和底部命令坞的边界、留白、标题层级和对比度。
- 保持五页命令、按钮语义命中框、至少 44pt 的触控命中、pending 高亮、选择/生产/支援/AI/重开状态完全不变。
- 使用现有 SpriteKit shape 和 label 完成，不引入外部素材或依赖；通过云端 build、现有 24 张截图探针和新增 UI 静态检查确认回归。

## 非目标

- 不修改战斗、移动、生产、AI、迷雾、胜负、地图地形和实体模型。
- 不新增 HUD action、输入手势、状态字段或第二套 UI 状态流。
- 不运行本地 Xcode build、Simulator、simctl 或本地探针。
- 不修改用户工作树已有的 `project.pbxproj` Team ID、未跟踪 v5.23–v5.33 提示词和 `md/unity分析/`。

## 当前架构依据

- `GameScene.swift` 的 `layoutHUD()` 负责创建所有 HUD 节点，`updateHUD()` 负责刷新文字和状态。
- `HudPage` / `HudAction` 保持现有页面和动作映射；`makeButton`、`makeHudPageTab`、`refreshHudButtonStyles` 负责按钮视觉状态。
- `addMinimap` 和 `addSelectionInfoPanel` 负责右上小地图与选择卡，`hudCommandStripFrame` 和命中字典负责底部交互隔离。
- 所有 HUD 节点挂在 `cameraRig -> hudNode`，跟随 resizeFill 和 `didChangeSize` 重建。

## 实现步骤

1. 在 `layoutHUD()` 中统一面板尺寸、圆角、描边、透明度、位置和字体层级，增强顶部资源、任务、状态和选择信息卡的层次。
2. 为底部命令条增加独立深色指挥坞背景、顶部标签层和更清晰的页签 / action 卡；视觉 frame 与既有 hit frame 继续分离。
3. 更新按钮与页签的填充、描边、armed / unavailable / active 状态和小型顶部高光，保持颜色之外仍有边框、文字和状态差异。
4. 更新小地图标题、边框与选择卡标题，使地图和目标信息在战场背景上保持可读。
5. 更新 README、`md/flow/flow.md`、`md/flow/flowchart.md`、`md/test/test.md` 和 `update_log.md`，只描述真实已实现的视觉变化与验证边界。
